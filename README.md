# Skanda Guru Transport — Static Website

A responsive, single-page business website built with plain HTML, CSS and JavaScript.

## Project structure

```text
transport project/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
```

## Run locally

1. Extract the project folder if it is in a ZIP file.
2. Open `index.html` in a web browser.
3. For a development server, open the folder in VS Code and use the Live Server extension.

No build tools, framework, database, or backend are required.
